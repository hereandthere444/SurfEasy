# **App Name**: SurfEasy

## Core Features:

- Address Bar: Address bar to input and display the current URL.
- Webpage Display: Display the content of the webpage.
- Navigation Buttons: Basic navigation buttons (Back, Forward, Refresh).

## Style Guidelines:

- Simple, clean layout with the address bar at the top and webpage content below.
- Neutral color palette (white, light gray) for the background.
- Accent color: Blue (#3498db) for the address bar and navigation buttons.
- Simple, recognizable icons for navigation buttons.
